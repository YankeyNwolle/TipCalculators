# Tip Calculator

Petite application Android (Kotlin + Jetpack Compose) qui calcule un pourboire à partir du montant de la facture et d'un pourcentage personnalisé, avec option d'arrondi.

Projet réalisé à partir du cours « Principes de base d'Android avec Compose » (Chapitre 8).

## Fonctionnalités

- Saisie du montant de la facture et du pourcentage de pourboire
- Calcul automatique du pourboire, mis à jour à chaque saisie
- Option « Round up tip? » pour arrondir à l'entier supérieur
- Interface adaptée au mode paysage (défilement vertical)
## Lancer le projet

1. Ouvrir le dossier dans Android Studio
2. Synchroniser Gradle
3. Lancer l'app (▶) sur un émulateur ou un téléphone

## Lancer les tests

- `TipCalculatorTests` (dossier `test`) : s'exécute sur l'ordinateur
- `TipUITests` (dossier `androidTest`) : nécessite un émulateur ou un appareil
